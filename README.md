About the Project

Welcome to my C++ Programs repository!

This repository contains basic C++ programs created as part of my programming practice and learning journey. These programs help me understand programming fundamentals, data structures, and logical problem-solving.

Programs Included

1. Palindrome.cpp – Checks whether a given number is a palindrome.
2. Stack Operations.cpp – Demonstrates basic stack operations using C++.

Technologies Used

- C++
- Conditional Statements
- Loops
- Functions
- Data Structures
- Stack Operations

How to Run

1. Navigate to the project folder.

2. Compile the program:

g++ Palindrome.cpp -o Palindrome

3. Run the program:

./Palindrome

For Stack Operations:

g++ "Stack Operations.cpp" -o StackOperations

./StackOperations

Note: On Windows, you can run the compiled executable using "Palindrome.exe" or "StackOperations.exe".
